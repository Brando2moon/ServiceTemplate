# Service Business Template

A reusable website and admin system for local service businesses.

## Website

- Home
- Services
- About
- Contact
- Before-and-after project gallery
- No public prices

## Admin

- Secure login
- Owner, Manager, and Employee roles
- Customer inquiries and quotes
- Service calendar and employee assignments
- Work notes and job photos
- Manager reschedule alerts
- Add, replace, remove, and publish before/after project photos
- Website colors, logo, contact details, and content
